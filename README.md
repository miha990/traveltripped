# TravelTripped

TravelTripped is a full-stack web application for searching, planning, and organizing trips. Users can browse travel destinations, hotels, and flights, and once logged in, create, view, and manage their own bookings.

## Features

- User registration, login, authentication and authorization (JWT)
- Browse and search travel destinations
- View hotels and detailed information
- Search and view available flights
- Create, view, and cancel bookings
- Automatic horizontal scaling and self-healing in Kubernetes

## Tech Stack

- **Frontend**: React 18, Vite, Tailwind CSS
- **Backend**: Spring Boot 3.2, Java 17, Spring Security, JWT
- **Database**: MongoDB 7.0
- **Containerization**: Docker, Docker Compose
- **Orchestration**: Kubernetes (Deployment, Service, Ingress, StatefulSet, HPA, ConfigMap, Secret, PVC)
- **CI/CD**: GitHub Actions, DockerHub
